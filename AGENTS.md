# Lazoya workflow

- The user wants completed website changes pushed live by default. After the relevant checks pass, commit and push the intended changes to `main`, then verify the corresponding Vercel production deployment and the public site at `https://www.lazoya.fr/`.
- A successful Git push is not proof of a successful deployment. Confirm the production deployment is READY for the pushed commit and check the affected public pages.
- Follow any newer user instruction to pause, work locally, avoid deployment, or use another branch. Read-only audits and discussions do not require a deployment.
- Preserve existing branding, services, booking journeys, analytics and Google Ads identifiers. Do not publish credentials or environment files.
